## Trigger Matching API

```javascript
// Match user intent to skills
const matches = await vault.match({
  query: "aimify this model",
  context: "Creating HyperCycle AIM",
  max_results: 5
});
```

## Creating Custom Triggers

Agents can define custom trigger phrases when creating skills:

```javascript
const skill = await vault.create({
  name: "my-custom-skill",
  triggers: [
    "custom trigger phrase 1",
    "another trigger phrase",
    "third way to activate"
  ],
  content: "..."
});
```
