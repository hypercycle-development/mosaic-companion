1 Download Mosaic

Choose the correct version for your system:

Installer (.exe) — x64 For 64-bit Windows (most common) recommended
💡

Edge browser users: Edge may flag the download as uncommon. Click the "···" (More actions) icon next to the file → "Keep" → then expand the "···" dropdown beside "Delete" and select "Keep anyway". Chrome and Firefox download without issues.

2 Install

Installer (.exe): Standard installation:

  • Double-click the downloaded .exe file
  • If Windows Defender SmartScreen appears, click "More info"
  • Then click "Run anyway"
  • The app will install and launch automatically
⚠️

Windows may show a warning because the app is not code-signed. This is normal for open-source software.

3 Launch Mosaic

  • Find Mosaic Companion in your Start Menu
  • Or look for the desktop shortcut
  • The app will launch and you're ready to go!

1 Download Mosaic

Choose the correct version for your Mac's processor:

Apple Silicon (.dmg) For M-series Macs (arm64) recommended Intel (.dmg) For Intel Macs (x64) recommended
💡

Not sure which version? Click the Apple menu → "About This Mac" → Look for "Chip" (Apple Silicon) or "Processor" (Intel).

2 Install the Application

DMG: Standard installation:

  • Open the downloaded .dmg file
  • Drag Mosaic Companion to your Applications folder
  • Eject the disk image when done

3 First Launch

Since Mosaic is not notarized by Apple, you'll need to allow it manually:

  • Open Applications and right-click on Mosaic Companion
  • Click "Open" from the context menu
  • Click "Open" again in the security dialog
⚠️

If you double-click directly, macOS may block the app. Always right-click → Open for the first launch.

4 Troubleshooting (Temporary for macOS)

Since Mosaic Companion is not yet code-signed, you may encounter additional security warnings. Here are temporary workarounds:

Option 1: Terminal Command (Immediate Fix)

If you trust the Mosaic's source, you can bypass this security check using the Terminal:

  1. Open Terminal from Applications > Utilities or via Spotlight search.
  2. Run the following command, replacing ~/MosaicCompanion/Mosaic\ Companion.app with the actual path to your application (you can type the command and then drag the application icon into the Terminal window to auto-fill the path):
xattr -cr /Applications/mosaic-companion.app

(Note: the -cr flags remove all extended attributes recursively).

Press Enter to execute the command. You may need to enter your administrator password.

Attempt to open the app again. It should now launch without the error.

Option 2: Override Security Settings

Go to System Settings > Privacy & Security, look for a message about Mosaic Companion (recently blocked) and click the "Open Anyway" button.

Note: This is a temporary measure while we obtain proper code signing. These steps will not be needed in future releases.

1 Download Mosaic

Choose the format that works best for your system:

Debian / Ubuntu (.deb) - Recommended:

deb — x64 For 64-bit Intel/AMD recommended deb — ARM64 For ARM 64-bit (Raspberry Pi 4+, etc.) recommended

AppImage (Universal, Portable):

AppImage — x64 For 64-bit Intel/AMD (x86_64) recommended AppImage — ARM64 For ARM 64-bit (aarch64) recommended

2 Install

AppImage: Make it executable and run:

chmod +x ~/Downloads/mosaic-companion*.AppImage && ~/Downloads/mosaic-companion*.AppImage

Debian/Ubuntu (.deb): Install with dpkg (or double-click the file to open your package installer):

sudo dpkg -i ~/Downloads/mosaic-companion*.deb
💡

On some newer distros, you might need FUSE for AppImage:

sudo apt install libfuse2

3 Run Mosaic

  • AppImage: Double-click the file or run from terminal
  • Deb: Find "Mosaic Companion" in your application menu
