Your AI-powered companion for seamless computing. Choose your platform below to get started.

1 Download Mosaic

Choose the correct version for your Mac's processor:

Mosaic Companion (Intel)
For Intel Macs (x64)
Mosaic Companion (Apple Silicon)
For M1/M2/M3 Macs (arm64)
💡

Not sure which version? Click the Apple menu → "About This Mac" → Look for "Chip" (Apple Silicon) or "Processor" (Intel).

2 Install the Application

  • Open the downloaded .dmg file
  • Drag Mosaic Companion to your Applications folder
  • Eject the disk image when done

3 First Launch

Since Mosaic is not notarized by Apple, you'll need to allow it manually:

  • Open Applications and right-click on Mosaic Companion
  • Click "Open" from the context menu
  • Click "Open" again in the security dialog
⚠️

If you double-click directly, macOS may block the app. Always right-click → Open for the first launch.

1 Download Mosaic

Choose the correct version for your system architecture:

Mosaic Companion (x64)
For 64-bit Intel/AMD (x86_64)
Mosaic Companion (ARM64)
For ARM 64-bit (aarch64)

Debian / Ubuntu (.deb):

Mosaic Companion (x64)
For 64-bit Intel/AMD
Mosaic Companion (ARM64)
For ARM 64-bit (Raspberry Pi 4+, etc.)

2 Make it Executable (AppImage)

If you downloaded the AppImage, make it executable:

chmod +x ~/Downloads/Mosaic*.AppImage

3 Run Mosaic

AppImage: Double-click the file or run ./Mosaic*.AppImage

Debian/Ubuntu: Install with right-click → Open with Software Install, or run:

sudo dpkg -i ~/Downloads/Mosaic*.deb
💡

On some newer distros, you might need FUSE for AppImage: sudo apt install libfuse2
