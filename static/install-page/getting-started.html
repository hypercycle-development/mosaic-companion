✦ Getting Started Guide

Get Started with MosAIc

Install Mosaic, connect a free AI model, and find your way around — no technical background needed. About 15 minutes, start to finish.

⬇

Phase 1 — Install Mosaic

Grab the installer for your system from the download page — it has step-by-step instructions for Windows, macOS, and Linux, including how to get past the "unsigned app" warnings you'll see on first launch (normal for open-source software that isn't code-signed yet).

Go to the download page →
✨

Phase 2 — The Setup Wizard

What you'll see

A short welcome tour

The first time Mosaic opens, a wizard walks you through:

  1. Welcome — click Get Started
  2. Features — a quick overview of what Mosaic can do
  3. Add your first AI agent — this is where your AI model gets connected. Keep this screen open and get your free key in Phase 3 →
Good to know

You can't get this wrong

  • Clicked Skip for now? No problem — you can add an agent anytime under Configuration → AI Agents → Add Agent (same fields as the wizard).
  • Want to see the wizard again? Configuration → Replay Onboarding.
  • An "agent" is just an AI model plus your key for it. You can add several and switch between them.
🔑

Phase 3 — Get a Free Gemini API Key

Google's AI Studio gives you a free key for the Gemini models — no credit card needed.

Step 01

Sign in

Go to AI Studio and log in with your Google account.

Open AI Studio ↗
Step 02

Find the API menu

Look for "Get API key" in the bottom-left sidebar, then the "Create API key" button in the top right.

Step 03

Create a project

In the popup, choose "Create Project", name it something like Mosaic, click Create, then the final "Create Key" button.

Step 04

Copy the key

Click the partial key text (e.g. ...kJsY) to reveal the full key, and copy it.

Treat it like a password — don't share or post it.

🔌

Phase 4 — Connect Gemini to Mosaic

Enter these details

In the wizard's agent screen

(or Configuration → AI Agents → Add Agent if you skipped the wizard)

ProviderSelect Custom Endpoint
NameAnything you like — e.g. Gemini
Modelgemini-3-flash-preview
Base URLhttps://generativelanguage.googleapis.com/v1beta/openai
API KeyPaste the key from Phase 3
Verify & save

Test the connection

  1. Switch the Active toggle ON (green)
  2. Click Test Connection
  3. Look for "Connection established successfully!"
  4. Click Save (or Continue in the wizard)

Your key is stored on this device only, encrypted with your computer's built-in keychain.

Test failed?
• "Quota exceeded" — free keys have small daily limits and occasionally start rate-limited. Your key is fine; wait a few minutes (or up to a day) and test again.
• "Invalid key / unauthorized" — re-paste the entire key with no extra spaces or line breaks.
• "Model not found" — Google renames models over time; check the current model list at ai.google.dev and use the newest "flash" model name.

Phase 5 — Say Hello & Find Your Way Around

First stop: AI Chat. After finishing the wizard Mosaic drops you straight into AI Chat — say hello to your new agent. You can always get back to it from the left sidebar (open it with the ☰ button, top-left).
The sidebar, decoded

What each section is for

AI ChatOne-on-one chat with your AI agents — this is the main chat, where you'll spend most of your time.
Mosaic BotA built-in background assistant with long-term memory. Different from AI Chat — think of it as Mosaic's own helper.
Chat RoomsShared rooms where several people and agents can talk together. Needs a chat server — safe to ignore at first.
MCP ServersOptional plug-ins that give your agents extra tools. Ignore until you need them.
Web 3Connect a crypto wallet, set transfer limits, and control what agents may spend. Only relevant if you use crypto.
VaultEncrypted boxes for your own notes and secrets — you choose which agents can read each box. Try it: create a box, put something in, and ask your agent what's in your vault.
AddonsOptional installable tabs (Settings → Addons) that add functionality beyond the core app — analytics, marketplaces, and more, added as they become available.
IDEA built-in code editor. For programmers — everyone else can skip it.
Tool SandboxInstall small, safely-sandboxed tools that agents can run. Optional.
ConfigurationSettings — including AI Agents, where keys and models live.
💡 Mosaic works like a browser: the + button at the top opens everything in tabs, exactly like the browser you already know.

Phase 6 — Staying Up to Date

Automatic

Mosaic tells you

When a new version is out, Mosaic shows an "Update Available" message when it starts, pointing you to the download page. Grab the new file and install it the same way you did in Phase 1. Your settings, agents, and vault stay put.

Manual

Check anytime

Open Configuration and click Check for Updates.

🛟

Troubleshooting

Agent doesn't answerMosaic shows the reason right in the chat (e.g. missing key, quota) with a pointer to fix it. Check Configuration → AI Agents: is your agent's Active toggle green, and does Test Connection pass?
"Quota exceeded"Free Gemini keys have small daily limits. Wait and retry — the key itself is fine. If you hit this often, create a second key in a new AI Studio project, or enable billing with Google.
"Connection failed"Re-copy the Model and Base URL from Phase 4 exactly (no extra spaces), and re-paste the full API key.
Mac: "app is damaged"Run xattr -cr /Applications/mosaic-companion.app in Terminal, or System Settings → Privacy & Security → Open Anyway. Full steps on the download page.
AppImage won't startMake it executable (chmod +x or right-click → Properties), and on newer Ubuntu install FUSE: sudo apt install libfuse2.
Something elseOpen an issue at github.com/hypercycle-development/mosaic-companion.
