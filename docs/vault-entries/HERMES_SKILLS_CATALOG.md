## Skill Format Reference

All Hermes skills follow the SKILL.md format:

```markdown
---
name: skill-name
description: "What this skill does"
trigger: "When to activate this skill"
category: category-name
version: 1.0.0
platforms: [linux, macos, windows]
---

# Skill Title

## When to Use
- Condition 1
- Condition 2

## Steps
1. Step one
2. Step two

## Pitfalls
- Common mistake 1
- Common mistake 2
```

**To import a Hermes skill into Mosaic Bot:**
1. Copy the SKILL.md from `~/.hermes/skills/<category>/<skill-name>/`
2. Place it in `electron/integrations/mosaicbot/bundled-skills/<skill-name>/SKILL.md`
3. Restart Mosaic Companion
4. The skill will be auto-loaded by `loadSkillEntries()`
