## Recovery Procedures

### If SPO is Down
1. Check physical/virtual machine status
2. Restart SPO service
3. Verify network connectivity between SPO and boxes
4. Re-register boxes once SPO is up

### If HBA is Down
1. SSH to the box (C-3PO or R2D2)
2. Check HBA process: `ps aux | grep hba`
3. Restart HBA agent if needed
4. Re-run heartbeat registration to SPO

### If Tiller Not Found
1. Check Docker: `docker ps | grep tiller`
2. If no tiller container, check Node Manager UI for AIM status
3. Start tiller via Node Manager or manual Docker run
4. Update HBA agent config with correct tiller port
